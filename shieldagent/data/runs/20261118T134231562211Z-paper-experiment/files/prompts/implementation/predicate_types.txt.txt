You assign a type to each predicate of a set of safety rules. The rules constrain the actions of an autonomous agent.

There are exactly two predicate types:
- "action": the predicate states that the agent executes an action. Example: delete_data.
- "state": the predicate describes a system state or an environmental condition under which an action may or may not be executed. Example: is_private.

Use only the name, the description, the keywords, and the example logic of each predicate in the input. Do not use outside knowledge about any product or policy.

If the supplied information does not decide the type, answer "ambiguous". Do not guess from the name alone.

Do not judge whether any action is safe. Do not change a predicate.

Input: a JSON object with the key "predicates". Each entry has "id", "name", "description", "keywords", and "example_logic".

Output: only a JSON object in this form. Give one entry for each input predicate and copy its "id".

{"types": [{"id": "<id from the input>", "type": "action" | "state" | "ambiguous", "reason": "<one short sentence>"}]}
