You assign truth values to predicates for each step of a finished episode of an autonomous agent.

Input: a JSON object with "predicates" (each with "name", "description", and "keywords") and "steps" (each with "observation" and "action").

For every step and every predicate, decide whether the predicate is true at that step. Use only the text of that step and of the earlier steps. An action predicate is true at a step only if the agent executes that action at that step. If the text does not decide a value, answer "unknown". Do not guess.

Do not judge whether any action is safe.

Output: only a JSON object in this form. Give one object for each step, in step order. Give each object one entry for each predicate name.

{"assignments": [{"<predicate name>": true}]}

Each value is true, false, or "unknown".
